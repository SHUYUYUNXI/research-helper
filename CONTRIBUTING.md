# Contributing to 联网找资料助手

Install Python 3.10+ and this local project with `python -m pip install ".[dev]"` in a virtual environment.
Run `python -m unittest discover -s tests_reachkit -v` and `python -m pytest tests -q`.

Keep operation routing, capability metadata, doctor output, skill references and package resources consistent. Preserve upstream licenses and document changes in NOTICE and CHANGELOG.md. Verify real platform results separately from mocked tests. Do not commit credentials or generated source archives to the source tree.
